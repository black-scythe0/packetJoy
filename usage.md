### USAGE
--
**Show all ip addresses available to investigate (in local network) with appropriate info.** --


- Eg:
```sh
 pJ -all
```
**Sniffing packets.**
- Eg: 
```sh
pJ -sniff <ip addr> -p <port no.>
```
or
 
- Eg:
```sh
 pJ -sp <ip addr> -p <port no.>
```
 
**To sniff all packets it can sniff.**
- Eg:
```sh
pJ -sniff <ip addr> -all
```
or 
  
- Eg:
```sh
pJ -sp <ip addr> -all
```
**To check.**
- running services.
- Eg:
```sh
pJ -rs <ip addr>
```
- available ports.
- Eg: 
```sh
pJ -ap <ip addr>
```
